# 7. Input dan aksesibilitas · planned

Pastikan alur memilih tujuan, mengisi nama, dan membaca hasil bisa digunakan dengan cara input yang tersedia di setiap platform.

**Done when:** alur dapat diselesaikan dengan sentuhan, papan ketik, dan penunjuk. Dalam jendela sempit dengan teks besar, tombol tetap terjangkau, fokus mengikuti urutan tindakan, dan setiap kontrol memiliki label yang dapat dikenali. VoiceOver di iPad dan TalkBack di Android membacakan hasil baru. Tema menjaga kontras dan mengikuti preferensi pengurangan gerakan bila ada animasi. Langkah uji tersimpan agar dapat diulang saat tema dan terjemahan terpasang. AC 17, 18.
