## Catatan yang perlu kamu tahu

1. **Peringatan build.** Hanya dua jenis, masing masing satu kali per build. `Traditional headermap style is no longer supported ... set 'ALWAYS_SEARCH_USER_PATHS' to NO` sudah diketahui dan sedang ditangani architect lewat pembaruan spec, jadi bukan FAIL. `appintentsmetadataprocessor ... Metadata extraction skipped, no AppIntents.framework dependency found` adalah informasi bawaan Xcode untuk aplikasi tanpa App Intents. Tidak ada peringatan lain dan tidak ada baris `error:`.
2. **Folder kosong di luar repo.** Sesudah langkah 4 dan 7 muncul `~/Library/Developer/Xcode/DerivedData/Tablet-eandhqqraujzrvgepbinwewtlslz/` berisi lima folder `Logs/*` kosong (0 byte). Kedua langkah berjalan pada menit yang sama, jadi saya tidak bisa memastikan langkah mana yang membuatnya; dugaan saya `xcodebuild -list`, yang tidak menerima `-derivedDataPath`. Ini di luar repo, jadi tidak melanggar aturan "di dalam repo hanya menulis ke `target/` dan `apps/ipados/build/`". Folder itu sudah saya hapus. Layak diketahui untuk CI (fitur 11).
3. **Jalur yang tidak teramati.** Pemeriksaan prasyarat lain pada skrip (Command Line Tools terpilih, Xcode bukan 27, peringatan versi berbeda dari `.xcode-version`, target Rust belum terpasang, `cargo` tidak ada) tidak bisa dipicu tanpa mengubah mesin. AC-8 hanya meminta percobaan `DEVELOPER_DIR=/tidak/ada`, dan itu lulus.
4. **Toolchain dan cache sudah ada.** Rust 1.99.1 dengan kedua target Apple sudah terpasang, dan cache registry Cargo sudah terisi. Build dari clone bersih teramati; pemasangan dari nol dan unduhan dependensi tidak teramati di sini.
5. **Lokasi clone.** Clone dibuat di folder scratchpad sesi, bukan lewat `mktemp -d` polos. Bentuknya tetap `<folder sementara>/tablet`.
6. **Bentuk perintah langkah 17.** Pemeriksaan keamanan alat sesi menolak `rm -rf "$(dirname "$CLONE")"` karena targetnya substitusi perintah. Yang dijalankan adalah `cd / && rm -rf <path literal yang sama>`. Hasilnya sama.
7. **`codesign -dv` keluar 1** pada app Release. Itu perilaku `codesign` untuk objek tanpa tanda tangan, dan teksnya sama dengan yang diminta langkah 10.
8. Path clone pada log di bawah diganti dengan `$CLONE`. Selain itu keluaran ditulis apa adanya. Log build penuh (815 baris) diringkas ke baris penanda, baris perintah `xcodebuild`, dan peringatan.
