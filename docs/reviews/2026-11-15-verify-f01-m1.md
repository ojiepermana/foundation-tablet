## Catatan yang perlu kamu tahu

1. **Toolchain sudah terpasang sebelum langkah 1.** Rust 1.99.1 beserta keempat target, `rustfmt`, dan `clippy` sudah ada di mesin ini, jadi `rustup toolchain install` melapor `using existing install`. Langkah itu lulus sesuai teksnya (keluar 0 dan keadaan terpasang benar), tetapi pemasangan dari nol di mesin tanpa toolchain belum teramati. Itu bisa dibuktikan kelak oleh CI (fitur 11) pada runner baru.
2. **Cache registry Cargo sudah terisi.** `cargo build --locked` tidak mengunduh crate apa pun. Build dari clone bersih teramati; unduhan dependensi dari jaringan tidak teramati di sini.
3. **Lokasi clone.** Clone dibuat di folder scratchpad sesi, bukan lewat `mktemp -d`. Bentuknya tetap sama: `<folder sementara>/tablet`.
4. **Bentuk perintah langkah 15.** Pemeriksaan keamanan alat sesi menolak `rm -rf "$(dirname "$CLONE")"` karena targetnya berupa substitusi perintah. Perintah yang dijalankan adalah `cd / && rm -rf <path literal yang sama>`. Hasilnya sama: folder sementara terhapus.
5. **`Cargo.lock` memuat `uniffi_bindgen` dan `uniffi_udl` 0.32.2.** Keduanya tercatat di lockfile sebagai dependensi opsional `uniffi`, tetapi tidak ikut terkompilasi (lihat daftar `Compiling` langkah 3). Ini tidak melanggar AC-2. Dicatat supaya fitur 03 tahu versinya sudah terkunci.
6. Path clone pada log di bawah diganti dengan `$CLONE` supaya terbaca. Selain itu keluaran ditulis apa adanya.
