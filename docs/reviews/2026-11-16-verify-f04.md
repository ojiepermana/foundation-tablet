## Temuan dan pemulihan

- Kompilasi test Android pertama gagal karena nama helper `performReplaceText` tidak ada. Tes diperbaiki menjadi API `performTextReplacement`, lalu suite asli dan snapshot lulus. Tidak ada mock FFI.
- V7 menemukan build setting test di project.pbxproj. Identitas test dipindah ke `Config/UITests.xcconfig`; sumber versi tetap Base.xcconfig. V7 dan build snapshot sesudah perbaikan lulus.
- Pemeriksaan artefak pertama di checkout pengguna menghasilkan FAIL hanya pada HI4/HA5 karena perubahan implementasi belum di-commit. Pemeriksaan dipindah ke snapshot Git bersih, tanpa melonggarkan asersi; kedua kasus dan semua artefak kemudian PASS.
- Boot emulator dua kali tertahan kebutuhan partisi data bawaan dan ruang disk. Pendekatan diganti memakai image ext4 sparse 2 GiB pada AVD khusus melalui opsi `-data` yang didukung emulator. Pemeriksaan ruang disk tetap aktif; Android boot lengkap, sw800dp, lalu tes lulus. Tidak ada cache pengguna atau AVD lain yang dihapus.
- Peluncuran perangkat fisik, hosted CI, emulator x86_64 dan pemeriksaan UI tahap 05 sampai 07 tidak diklaim dari hasil lokal ini.
