- **Tanggal:** 2026-11-15
- **Spec:** [0001 arsitektur dan build awal](../specs/0001-arsitektur-dan-build-awal/index.md), Build plan 6 sampai 8
- **Commit yang diuji:** `5472d3a` (branch `claude/dev-f1-m1-ee7069`)
- **Mesin:** Mac M1 Max, macOS 27.0.1, Rust 1.99.1 dengan keempat target matriks, cargo-ndk 4.1.2, Android SDK di `~/Library/Android/sdk` (platform `android-37.0`, build-tools 36.0.0, NDK 28.2.13676358), JBR 25.0.2 dari Android Studio. `ANDROID_HOME` dan `JAVA_HOME` tidak diset; `java` di PATH hanya stub macOS `/usr/bin/java`, yang tidak dipakai skrip.

- **Ditulis oleh:** developer `dev-f1-m1`. Ini bukti build developer, bukan hasil `/check verify`.

## Catatan

- **Tafsiran AC-7:** `aapt2` 36.0.0 mencetak `minSdkVersion:'29'`, bukan `sdkVersion:'29'` seperti teks AC. Nilainya sama dengan `minSdk` katalog, jadi baris itu dianggap memenuhi AC. Langkah verify memakai `grep -E 'SdkVersion|compileSdkVersion='`.
- **Pustaka `.so` lain di APK:** `lib/arm64-v8a/libandroidx.graphics.path.so` dan `lib/x86_64/libandroidx.graphics.path.so` berasal dari Compose (`androidx.graphics:graphics-path`). Keduanya hanya di dua folder ABI matriks, sesuai AC-7.
- **Tanpa cadangan:** JDK 25, aksesor `libs` di blok `buildscript`, bentuk `compileSdk = 37`, dan `android.builder.sdkDownload=false` semuanya diterima apa adanya.
- **Wrapper:** dibuat dari `gradle-9.5.1-bin.zip` (SHA-256 `bafc141b…b031f`, sama dengan halaman checksum Gradle dan spec). SHA-256 `gradle-wrapper.jar` `497c8c2a…a9c7`, sama dengan `gradle-9.5.1-wrapper.jar.sha256` yang diterbitkan Gradle.
- **Waktu:** build pertama di worktree (cache kosong) 1 menit 54 detik untuk Gradle; dari clone bersih dengan cache terisi 50 detik total.
