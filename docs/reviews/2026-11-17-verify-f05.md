## Percobaan yang tidak dihitung lulus

- Grup artefak pada checkout utama mula mula gagal HI4 karena edit sumber belum di-commit. Run worktree bersih membuktikan hasil generasi tidak bocor. Edit sumber bukan bukti build mengotori tree.
- Tes compact pertama berhenti pada prasyarat background. Home pada Windowed Apps dengan scene tambahan tidak membuat proses background. Penyiapan berikutnya memakai satu scene dan Settings layar penuh, bukan menghapus assertion aplikasi.
- Pemulihan window compact pada Pro dan mini menyebabkan proses sistem `backboardd` crash di `MTLTextureDescriptorInternal validateWithDevice`, dengan pesan `MTLTextureDescriptor has invalid pixelFormat (0)`. XCTest merestart runner dan mencetak 0 tes setelah crash. Baris 0 tes itu tidak dihitung PASS. Log: `ui-compact-background.log`, `ui-mini-compact.log`; laporan sistem `backboardd-2026-11-17-231543.ips`, `...231705.ips`, `...232028.ips`.
- API publik UIKit untuk mengabaikan gambar launch dicoba melalui flag DEBUG simulator. Percobaan itu tetap menghentikan backboardd, sehingga seluruh flag dan kode percobaan dibuang. Storyboard launch dari template Xcode juga dicoba, tidak memperbaiki crash, lalu dibuang. Source aplikasi kembali identik dengan source awal yang build dan empat tesnya lulus.
- Pembersihan hanya cache grafis SplashBoard pada aplikasi uji juga tidak memperbaiki crash. Hash seluruh arsip scene dibandingkan sebelum dan sesudah dan tetap identik. Tidak ada seed atau perubahan state navigasi. Log percobaan di `launch-cache-repair.json`, `restore-sidebar.json`, `ui-mini-snapshot-workaround.log`, dan `ui-mini-launchscreen-template.log`. Semua percobaan ini bukan PASS pemulihan panel.
- Runtime 26.5: perangkat yang sudah ada, reboot, lalu simulator baru `D300D24B-2FEF-4542-B649-AC11D0EF2E33` dicoba. Startup tertahan sebelum UI operasional. Tes tidak berjalan, NOT_RUN. Bukti: `ui-26.log`, `ui-26-retry.log`, `26-fresh-boot.png`. Runtime 27.1 yang terpasang menolak pembuatan iPad sebagai incompatible device. Tidak dianggap target iPad yang tersedia.
- Perangkat fisik: NOT_RUN karena tidak terhubung. Release hanya bukti kompilasi dan artefak unsigned.
- Android: NOT_RUN karena scope 05 hanya presentasi iPad, tidak mengubah Rust, kontrak, binding, atau sumber daya bersama. Bukan klaim Android sudah memiliki navigasi ini.

## Verifikasi compact yang ditunda

Pemulihan visual panel daftar dan konten dalam window compact belum terverifikasi karena compositor sistem berhenti pada kedua simulator iPadOS 27.0 yang dicoba. Arsip scene nyata sudah membuktikan tujuan dan panel tersimpan, tetapi itu tidak menggantikan bukti layar setelah pemulihan. Perlu iPad fisik atau runtime iPad lain yang dapat menyelesaikan skenario ini. `xcrun devicectl list devices` hanya menampilkan perangkat simulasi. Permintaan target tambahan sudah disampaikan, tanpa meminta pengabaian kriteria.

Penundaan ini tidak mengubah hasil compact menjadi PASS. Pengguna kemudian memperjelas bahwa verifikasi compact boleh ditunda sambil scope 05 diselesaikan. Pengecualian penutupan tersebut tercatat di spec dan scope; tidak ada permintaan target tambahan yang menahan penutupan.
