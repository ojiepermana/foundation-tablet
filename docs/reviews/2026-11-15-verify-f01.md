## Batas bukti

- **Mesin ini bukan mesin kosong.** Toolchain Rust 1.99.1 dengan keempat target, `cargo-ndk` 4.1.2, distribusi Gradle 9.5.1, dan cache Maven sudah terpasang. `rustup toolchain install` dan `cargo install` hanya memastikan versi, dan Gradle tidak mengunduh distribusi. Pemasangan prasyarat dari nol (Xcode, rustup, Android SDK, JDK) tidak teramati, jadi bagian "Cara memasang prasyarat" hanya diperiksa isinya, bukan dijalankan.
- **Yang benar benar dibangun dari nol di clone:** semua keluaran Cargo (`target/` tidak ada sebelumnya), kedua app iPad, dan APK (`36 actionable tasks: 36 executed`).
- Angka "sekitar 151 MB" dan "sekitar setengah menit" di panduan tidak teramati di sini karena cache sudah ada.
- Aplikasi tidak diluncurkan di simulator, emulator, atau perangkat. Fitur 01 hanya menjanjikan build; peluncuran milik fitur 04 dan langkah manual.

## Temuan di luar AC (untuk developer, tidak menahan verdict)

1. **Baris pembersihan panduan gagal bila diikuti apa adanya.** `docs/getting-started.md` bagian "Lokasi hasil build" menulis `(cd apps/android-tablet && ./gradlew --stop)`. Dengan `JAVA_HOME` tidak diset (keadaan bawaan yang panduan sendiri anjurkan), perintah itu keluar `1` dalam 0 detik: `The operation couldn't be completed. Unable to locate a Java Runtime.` Daemon Gradle 9.5.1 tetap hidup. Bagian "Masalah umum" memang menyebut bahwa `./gradlew` langsung butuh `JAVA_HOME`, tetapi baris pembersihan tidak mengatakannya. Saran: tulis baris itu dengan `JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"` di depannya, seperti langkah penutup di `verify.md`.
2. **Panduan mengandaikan Android Studio ada.** Tidak ada tautan atau perintah untuk memasang Android Studio, `cmdline-tools`, atau JDK 25 berdiri sendiri. Kontributor tanpa Android Studio tidak punya jalur pasang JDK 25 yang tertulis. Kalimat "JBR bawaan Android Studio sudah JDK 25" benar untuk Android Studio 2026.1 di mesin ini (`openjdk version "25.0.2"`), dan bisa tidak benar untuk versi lain.
3. **Dua peringatan App Intents** (`Metadata extraction skipped, no AppIntents.framework dependency found`) tetap tercetak pada tiap build iPad. Itu sudah dicatat di `rationale.md` K29 sebagai informasi bawaan.
