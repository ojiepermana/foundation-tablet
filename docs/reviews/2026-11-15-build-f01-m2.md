## Peringatan dari build Xcode (tidak menggagalkan build)

```text
   1 appintentsmetadataprocessor[7229:95991795] warning: Metadata extraction skipped, no AppIntents.framework dependency found
   1 appintentsmetadataprocessor[7790:95993161] warning: Metadata extraction skipped, no AppIntents.framework dependency found
   2 warning: Traditional headermap style is no longer supported; please migrate to using separate headermaps and set 'ALWAYS_SEARCH_USER_PATHS' to NO. (in target 'Tablet' from project 'Tablet')
```

- `Metadata extraction skipped, no AppIntents.framework dependency found`: informasi bawaan Xcode untuk aplikasi tanpa App Intents.
- `Traditional headermap style is no longer supported ... set 'ALWAYS_SEARCH_USER_PATHS' to NO`: muncul karena `Base.xcconfig` sesuai spec tidak menyetel `ALWAYS_SEARCH_USER_PATHS`. Menambah `ALWAYS_SEARCH_USER_PATHS = NO` akan menghilangkannya, tetapi spec menetapkan isi xcconfig yang persis, jadi itu keputusan architect.
