# Bukti build fitur 01 milestone 4: panduan mulai singkat dan pengulangan clone bersih

- **Tanggal:** 2026-11-15
- **Spec:** [0001 arsitektur dan build awal](../specs/0001-arsitektur-dan-build-awal/index.md), Build plan 9, 10, dan 11
- **Commit yang diuji:** `7c687cc` (branch `claude/dev-f1-m1-ee7069`), berisi `docs/getting-started.md`, lima dokumen `docs/architecture/`, dan baris `ALWAYS_SEARCH_USER_PATHS = NO` di `Base.xcconfig`
- **Mesin:** Mac M1 Max, macOS 27.0.1, Xcode 27.1 (27A9275), rustup 1.29.3, Android SDK di `~/Library/Android/sdk`, JBR 25.0.2 dari Android Studio. `ANDROID_HOME`, `JAVA_HOME`, dan `DEVELOPER_DIR` tidak diset.
- **Cara:** `git clone` worktree ke folder sementara di luar repo, lalu enam perintah bagian "Perintah repo" di `docs/getting-started.md` dijalankan apa adanya dari akar clone, berurutan (Xcode selesai dulu, lalu Gradle). Sesudahnya daemon Gradle dimatikan dan clone dihapus. Total 126 detik.
- **Ditulis oleh:** developer `dev-f1-m1`. Ini bukti build developer, bukan hasil `/check verify`.

## Batas bukti

Mesin ini bukan mesin kosong. Toolchain Rust 1.99.1 dengan keempat target, `cargo-ndk` 4.1.2, distribusi Gradle 9.5.1, dan cache Maven sudah terpasang dari milestone 1 sampai 3, jadi `rustup toolchain install` dan `cargo install` hanya memastikan versi (keduanya keluar 0), dan Gradle tidak mengunduh apa pun. Waktu pemasangan pertama yang dicatat milestone 3: `cargo install cargo-ndk` sekitar 26 detik, distribusi Gradle sekitar 151 MB. Pemasangan dari nol (Xcode, rustup, Android SDK) belum diulang di mesin baru; panduan menulis langkahnya dari sumber resmi dan pesan skrip.
